**ZenDraw** is a high-performance, minimalist digital canvas designed for creators, thinkers, and builders. It provides an infinite space to sketch ideas, take notes, and brainstorm without the clutter of traditional drawing apps.

🔗 **Live Demo:** [scratchpad.vercel.app](https://scratchpad.vercel.app)

---

## ✨ Why ZenDraw?

Traditional drawing tools are often either too complex (overwhelming UI, heavy performance) or too primitive (lacking basic structure). ZenDraw bridges this gap by offering:

- **Zero Friction**: Start drawing the moment you open the app.
- **Infinite Freedom**: No boundaries. Pan and zoom across a limitless workspace.
- **Intelligence**: Built-in shape detection turns rough sketches into perfect geometry.
- **Organization**: Built-in Notebooks and Pages system to keep your thoughts structured.

---

## 🚀 What's Inside?

### 🎨 Core Features
- **Infinite Canvas**: Drag, zoom, and explore a limitless space.
- **Intelligent Shape Straightening**: Rough circles and squares automatically snap into perfect forms.
- **Notebooks & Pages**: Manage multiple projects with a familiar notebook-style hierarchy.
- **Pressure Sensitivity**: Optimized for styluses and touch inputs for a natural drawing feel.
- **Neon Glow Mode**: Create stunning visuals with vibrant, glowing strokes.
- **Image Support**: Drag and drop images, resize them, and lock them to the canvas for tracing or annotation.

### 🛠️ Technical Stack
- **React 19**: Modern component architecture.
- **Vite**: Ultra-fast build tool and dev server.
- **Canvas API**: High-performance rendering for smooth 60FPS drawing.
- **Framer Motion**: Fluid, premium UI animations.
- **Lucide Icons**: Crisp, modern iconography.

## 🛠️ How to Run Locally

Get ZenDraw up and running on your machine in seconds:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/scratchpad.git
   cd scratchpad
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

## 🎹 Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |

| <kbd>Ctrl/Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | Redo |
| <kbd>Del/Backspace</kbd> | Delete Selected Image |
